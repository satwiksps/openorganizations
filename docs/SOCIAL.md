# Social images

- [Landscape preview](../static/social/openorganizations-landscape-v2.jpg): website link previews and landscape posts (1200 × 630).
- [Square card](../static/social/openorganizations-square-v2.jpg): square social posts (1080 × 1080).

Both show a straight browser window under a teal spotlight, with all seven program logos. Artwork is AI-generated; small interface details are illustrative. The live directory remains the source of current counts and program coverage.

The website sets Open Graph and large Twitter card metadata automatically. To set GitHub’s repository preview once the repository is public, open Settings → General → Social preview and upload the landscape image.
